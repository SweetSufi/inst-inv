Behind the Investigation: Research Note

Investigation
17 — The Door
Primary capability
Interactive Environmental Design & Visual State Transitions
Prompt Engineering Method
State-Machine Prompting with Spatial and Transition Constraints
Development Method
One-shot AI-assisted website development
Research Question
How can AI-assisted development create coherent, interactive transitions between radically different imaginary environments while preserving a consistent architectural entry point?

Capability demonstrated

Interactive environmental design and visual state transitions: using AI assistance to build a browser experience in which one fixed threshold, an ordinary office door, leads to six visually unrelated environments. The capability is about coherence across change. The door, the camera move, the sound and the return path behave identically every time, while the world behind the door changes completely.

Prompt engineering method: state-machine prompting

The build brief describes the site as a set of named states and the allowed moves between them, rather than as a list of pages. It names the states (corridor with the door closed, door opening, world visible, return), says what must be true in each one (no world visible before the door opens, office ambience only in the corridor, harp only during a world) and states the events that cause a move (open the door, return). It also forbids certain moves, such as repeated harp playback from incidental pointer movement.

Spatial and transition constraints are added to that skeleton: the door is the only entrance, it swings on its hinges, the visitor must be able to return from every world, all six worlds must stay reachable, and each world has its own palette, composition and motion. The AI assistant turned those rules into code. The method applies to how the site was written. It does not run when a visitor uses the site.

How the experience works

The visitor starts in the corridor with office ambience playing after the first click or key press. Selecting the door swings it open on its right-hand hinges, the camera moves through the opening, the ambience fades and the harp begins. Each world responds to the pointer, touch or keyboard. Staircases glide and reconnect; the two suns move and change the light and shadows; the city turns over; the mirror pulls the visitor through to different rooms; the hotel's plants sway and grow vines where touched; and an occasional train passes the station with other worlds in its windows. Returning closes the door and the office ambience resumes. The next opening shows the next world, in a fixed order, so all six are reached.

Actual technical implementation

A single page of HTML, CSS and JavaScript. The corridor is the supplied image; the door leaf is a clipped copy of it that rotates in CSS 3D around the hinge edge, with the world image sitting behind it. The camera move is a CSS transform. Each world is drawn on one HTML canvas from the supplied artwork using layered and mirrored image tiles, parallax, procedural clouds, masked sway regions, a keyed sky for the desert, and recursive image drawing for the mirror. Audio uses the two supplied recordings with scripted volume fades. These are two-dimensional layers with perspective effects, not a three-dimensional scene. Fonts are Kingsland and Borel from the supplied files and Nunito Sans from Google Fonts.

Live LLM or deterministic state management?

Deterministic state management. The deployed site makes no calls to a language model or any other AI service. Progression is an in-memory counter that advances one world per opening. The only randomness is cosmetic, such as the timing of trains and the clock hands. AI assistance was used to write the code during development.

Relevant technical limitations

  • The worlds are flat artwork animated in layers. Movement is limited by what can be separated from each source image.
  • Browsers block audio until the first click, tap or key press, so the office ambience starts then.
  • Nunito Sans is loaded from Google Fonts and needs a network connection; a system sans-serif is used if it fails to load.
  • Testing was done in a desktop preview browser. Safari, physical phones and tablets, and screen readers were not independently tested.
  • With reduced motion enabled, the door swing and camera move become short fades and ambient drift stops.

Environmental state management

The page moves through four states: corridor, opening, world and leaving. Clicking the door is accepted only in the corridor state and Return to Office only in the world state, so repeated clicks cannot start a second opening or stack audio. A counter chooses the next world, advancing one step per opening and wrapping to the first after the sixth. It lives in memory, so reloading the page restarts at World 01. The corridor, door and plaque are restored exactly on every return.

Image and audio integration

The corridor, the six worlds and the Institute fonts (Kingsland, Borel) are the supplied files. The desert artwork has a keyed-out copy so its suns can move behind the buildings. The office ambience loops in the corridor and is started by the first click, tap or key press. Opening the door fades it out over about a second while the harp recording fades in; returning reverses this. The Sound control mutes both recordings and shows Sound on only after the browser has actually started playback.

Interaction

The whole door and its plaque are one click target shaped to the door. Hovering warms the door softly and keyboard focus outlines its silhouette. Inside the worlds, moving the pointer shifts perspective, dragging or scrolling moves along the scene, and clicking triggers each world’s own response. Arrow keys, Enter and Escape give the same controls from the keyboard.

What the investigation demonstrates

That a brief written as states, transitions and spatial rules can guide AI-assisted development toward an interactive site with a consistent entry point and reliable navigation, and that the same threshold can carry a visitor between environments with very different color, atmosphere and behavior.
