The Institute of Unnecessary Research

Investigation

20 — The Wonder/Wander Lab

Primary Capability

Experimental Interaction Design & Creative Computation

Research Question

How can AI-assisted creative computation create an immersive, tactile environment that encourages curiosity, relaxation, and open-ended exploration?

Prompt Method

Constraint-based prompting, used in the development prompt. The build prompt sets explicit boundaries for what the AI may and may not create, then asks for the experience inside them. Two layers are kept separate: the development prompt directed the AI that wrote this site, and no prompt runs when a visitor uses it.

Constraints taken from the actual build prompt:

  • No missions, scores, timers, challenges, or productivity objectives.
  • No bright colors, dark backgrounds, or added architecture.
  • No explosions, confetti, flashing lights, or cartoon effects.
  • Real supplied audio only; no synthesized replacements.
  • A restrained object count, so the gallery never feels crowded.

Two visual references (a gallery photograph-style render and a sphere reference) and two audio recordings were supplied alongside the prompt. The creative principle stated in the prompt was Wonder without obligation.

Method

One-shot AI-assisted interactive website development using two visual references, two supplied audio recordings, and a single integrated build prompt.

How It Works

Visitors manipulate floating spheres, interact with translucent bubbles, and activate subtle sound responses inside a luminous virtual gallery.

Technical Implementation

The gallery image is a fixed CSS background that never moves. Every floating object is drawn on a single HTML canvas layered above it, redrawn each animation frame with the browser's requestAnimationFrame timer.

Motion. A lightweight physics loop gives each object a velocity, slow sinusoidal wandering with its own phase, damping, soft walls, and a gentle upward buoyancy for bubbles. Spheres exchange momentum in soft elastic contacts with capped speed. Depth sets each object's scale, opacity, shadow and a slight parallax shift.

Objects. Bubbles are drawn procedurally (gradients, a faint conic iridescent rim, highlights). Spheres are circular crops of the supplied sphere reference, cut out in the browser at load.

Interaction. Pointer events handle mouse and touch: hovering nudges bubbles, clicking or tapping divides or pops them, dragging throws spheres, and tapping empty space makes a ripple. Keyboard: arrow keys move a soft cursor, Enter or Space acts, and chime buttons are focusable. Occasional rare events (a bubble following another, a sphere slowly reversing, a small arc of bubbles) are scheduled by a timer with random intervals.

Audio. The supplied MP3 files are decoded with the Web Audio API into separate chime and bubble channels, each with its own gain, through a master gain and compressor. Each sound plays as a short, randomly chosen, faded segment of the recording, with cooldowns and a cap on overlapping voices. Audio starts only after the visitor presses the sound control.

Accessibility. Reduced-motion preferences stop continuous drifting while objects remain interactive; a toggle also switches this on or off.

AI Transparency

AI assisted the development: it wrote the HTML, CSS, JavaScript and this note from the prompt and references. The deployed site contains no live AI. It makes no model calls and no network requests beyond loading its own files. Behavior is deterministic, rule-based physics with random variation from a standard random-number generator.

Limitations

The architectural background is a raster image, so it softens when scaled to wide screens. Chime positions are matched to the image by hand. Audio needs a browser that supports Web Audio and a visitor gesture to begin. Testing was limited to the build environment's browser preview, not a range of devices.

What This Demonstrates

Human-centered experimental interaction design, creative computation, nonverbal interfaces, responsive animation, and the integration of sound and movement into a coherent digital experience.
