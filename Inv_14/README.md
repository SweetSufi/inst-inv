# The Internet's Smallest Art Studio — Investigation 14

Static site for GitHub Pages. No build step.

## Deploy
1. Create a repository and upload the contents of this folder to the root (index.html, support.js, assets/, audio/, fonts/, .nojekyll).
2. Settings > Pages > Source: "Deploy from a branch", branch main, folder / (root).
3. Open the published URL.

## Notes
- Nunito Sans loads from Google Fonts. Kingsland and Borel are bundled in fonts/.
- audio/rain.mp3 is a user-supplied recording and has not been auditioned or license-checked. Replace it with a gentle rainfall recording if needed.
- Gallery and unfinished drawing are stored in the browser's localStorage.
- Build: Inv14_Art_Studio. Stage 1 wall image and painting 01 are supplied artwork; paintings 02-06 are generated placeholders to be replaced with a matching set.
- Not yet tested: GitHub Pages deployment.
