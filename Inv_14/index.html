Behind the Investigation: Research Note

Behind the Investigation explains the generative AI capabilities, technologies, and design decisions demonstrated by each Institute investigation.

Institution: The Institute of Unnecessary Research
Investigation: 14 — The Internet's Smallest Art Studio
Primary Capability: Browser-Based Creative Tools & Constraint-Driven Visual Creation
Research Question: How can AI-assisted development create an immersive, accessible, browser-based art studio that encourages experimentation through creative tools and imaginative constraints?
Method: AI-assisted website development using approved visual assets and a comprehensive implementation prompt.

How It Works

The experience has four stages. Visitors enter a photographed studio, choose pencil, watercolor, ink or charcoal at a worktable, and draw on a canvas mapped onto the sheet of paper in the photograph. An optional creative challenge, drawn from a fixed list of 28, can be reshuffled at any time. Finished work is exhibited in a small gallery, where each painting can be enlarged, downloaded as a PNG or removed.

Technical Implementation

HTML, CSS and JavaScript only, hosted statically. Drawing uses Pointer Events on an HTML canvas, warped onto the photographed paper with a CSS perspective transform; pointer positions are mapped back through the inverse transform. Each medium uses its own stamping algorithm. Gallery paintings and the unfinished drawing are saved in the browser's local storage. The wall paintings are one crop from the approved studio photograph and five paintings generated on a canvas by script when the page loads. Rain sound plays from a locally bundled recording.

What This Demonstrates

Interactive creative tooling, direct manipulation, visual integration of interface into photographs, and constraint-driven creativity.

Implementation Transparency

The deployed experience uses browser-side drawing and predefined creative challenges. It does not use a live LLM or any model inference when visitors use it. AI assistance was used to write the code and the procedural paintings.

Limitations

The four media approximate physical materials within canvas limits. The studio photographs are fixed images, so the drawing surface is correct only for the camera angle they show. Browser storage holds roughly 5 MB, so a large gallery may reach the limit, and private browsing may not keep work between visits. After a refresh a saved drawing can be edited further, but earlier strokes cannot be undone. Nunito Sans loads from Google Fonts.
