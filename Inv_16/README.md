# Make It Balance (Investigation 16)

The Institute of Unnecessary Research. A browser-based balancing game.

## Publish on GitHub Pages
1. Upload the contents of this folder to a repository (index.html at the root).
2. Settings > Pages > Deploy from branch > main / root.

## Contents
- index.html: the game and Research Note
- support.js: runtime required by index.html
- assets/fonts: Kingsland, Borel
- assets/leberch-funny-playful.mp3: optional music (off by default)
- assets/MUSIC_LICENSE.md: music credit

Nunito Sans loads from Google Fonts and needs a network connection. Serve over http(s); opening index.html from a file may block assets.
