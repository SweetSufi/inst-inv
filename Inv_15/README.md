# Investigation 15: The Calm Screen
The Institute of Unnecessary Research

A meditative digital sand garden. Drag the sculpture to roll it across the sand. A gentle breeze moves the sand, with a wind sound that starts after the first interaction (sound on/off button at bottom right).

An AI-assisted interactive visual simulation, not a live generative AI model. No backend, login, or external API.

## Deploy
`index.html` is a single self-contained file (images, fonts and audio are embedded). Upload it to any static host.

GitHub Pages: push this folder to a repository, then Settings > Pages > deploy from the main branch, root folder.
